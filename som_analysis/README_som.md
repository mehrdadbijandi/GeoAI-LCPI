# SOM Analysis Scripts

Self-Organizing Map training, clustering, and visualization.

### Requirements
- Python 3.x
- MiniSom 2.3.1
- NumPy, Matplotlib, SciPy

### SOM Parameters (as reported in the manuscript)
- Grid: 9 × 13 (hexagonal)
- Learning rate: 0.5
- Neighborhood radius: 4.0 (Gaussian)
- Convergence criteria: QE < 1.0 and TE < 0.06
